# ViMod

### Plataforma de arquitectura para vivienda económica

ViMod es una plataforma web orientada al diseño y planificación de viviendas modulares económicas. Permite gestionar terrenos, crear proyectos de vivienda, generar propuestas de distribución y consultar estimaciones de costos según las necesidades del cliente.

## Características principales

- **Gestión de terrenos:** registro y administración de terrenos.
- **Proyectos de vivienda:** creación y gestión de proyectos personalizados.
- **Propuestas arquitectónicas:** generación de propuestas según las dimensiones del terreno y las necesidades del cliente.
- **Gestión de usuarios:** acceso diferenciado para clientes, arquitectos, constructoras y administradores.
- **Servicios y cotizaciones:** consulta de servicios y gestión de cotizaciones.
- **Pagos:** simulación académica de pagos e integración con Stripe en modo de prueba.

## Tecnologías utilizadas

- **Frontend:** HTML, CSS y JavaScript.
- **Backend:** Node.js y Express.
- **Base de datos:** MongoDB.
- **Pagos:** Stripe Checkout en modo de prueba.

## Objetivo

Facilitar la planificación de viviendas económicas mediante herramientas digitales que integren las necesidades del cliente, las propuestas arquitectónicas y las estimaciones presupuestarias.
